独立调整 load / store 延迟

单位ns · 改变窗口长度和S/L，重新计算所有统计
独立开关，选中立即设置20ns并重算；取消恢复此前非命中L。仅影响A/B/C自身类别，metadata/atomic不随缓存开关改变。命中带宽含cache侧payload，不能解读为HBM流量。

metadata沿其访问路径使用A-load或DMA代理；atomic保留所选原模型L。load和store条数分别统计；B等效/C等效缺口不能相加。自定义延迟是假设，不是新测量，也不改变原ATT发射时间。
